# Student Organizer

A web application for managing student organization, tutoring schedules, and communication between professors and tutors.

## Features

- User authentication and role-based access control
- Calendar management for tutoring sessions
- Email notifications for schedule confirmations
- Student progress tracking
- Real-time updates using Firebase
- Responsive design with Tailwind CSS
